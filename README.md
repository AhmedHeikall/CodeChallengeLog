# CodeChallengeLog

A personal collection of coding-challenge solutions and implementations for practicing data structures, algorithms, and common problem-solving patterns. The repository is organized by topic so solutions can be found and revisited easily.

## ⚙️ Topics Covered

<details>
  <summary>📘 Data Structures</summary>

- Arrays
- Linked Lists
- Stacks & Queues
- Trees (Binary, BST, Trie, AVL)
- Graphs
- Heaps / Priority Queues
- Hash Maps / Sets
- Strings

</details>

<details>
  <summary>🧠 Algorithms</summary>

- Sorting & Searching
- Recursion & Backtracking
- Divide and Conquer
- Dynamic Programming (DP)
- Greedy Algorithms
- Graph Algorithms (DFS, BFS, Dijkstra, Topological Sort)
- Bit Manipulation
- Sliding Window & Two Pointers

</details>

## Languages

The solutions currently use C++, Python, and Java. Each source file is maintained as an individual practice solution; there is no single application entry point or repository-wide build target.

## Learning goals

- Build a strong foundation in data structures and algorithms.
- Practice recognizing common problem-solving patterns.
- Improve solution efficiency by considering time and space complexity.
- Maintain a consistent record of coding practice.
